# @engineering-os/adapter-claude

Claude Code adapter for Engineering OS.

## How It Works

EOS connects to Claude Code via MCP (Model Context Protocol). No separate adapter code is needed — Claude Code connects directly to the EOS MCP server.

The integration is:
1. `.mcp.json` in your project points to `eos serve`
2. `CLAUDE.md` (generated by `eos init --claude`) instructs Claude to use EOS tools
3. Claude calls EOS MCP tools (`eos_context`, `eos_search`, etc.) automatically

## Generated CLAUDE.md

The enforcement file tells Claude:
- ALWAYS call `eos_context` before starting any task
- NEVER use grep/find/Explore — use `eos_search` instead
- ALWAYS call `eos_learn` when discovering something new
- NEVER make architecture decisions without checking `eos_recall_decision`

## Setup

```bash
eos init --claude
# Creates .mcp.json + CLAUDE.md
```
