# @engineering-os/adapter-vscode

VS Code extension scaffold for Engineering OS.

## Status

Scaffold only — provides extension entry point, sidebar provider, and command registration. Not yet published to VS Code Marketplace.

## Structure

- `extension.ts` — Extension activation/deactivation
- `sidebar-provider.ts` — Webview sidebar for architecture visualization
- `commands.ts` — Command palette integrations
- `config-generator.ts` — MCP configuration helper
