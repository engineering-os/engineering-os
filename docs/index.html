Quick Start

Three commands. Full intelligence.

# Install globally $ npm install -g engineering-os # Initialize in your project $ cd your-project && eos init --claude --cursor ✓ Repository indexed (847 files, 4201 chunks) ✓ Architecture discovered (12 services, 3 patterns) ✓ Graph built (156 calls, 4 contracts) ✓ CLAUDE.md generated ✓ .cursor/rules/ generated (5 files) ✨ Engineering OS initialized! # Link sibling services for full topology $ eos link backend ../backend-api $ eos link ml-pipeline ../ml-service # Done. Open Claude Code or Cursor — EOS is active.
